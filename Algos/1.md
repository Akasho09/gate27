## Algorithm :
> An algorithm is a step-by-step set of instructions used to solve a problem or complete a task.
- Think of it like a recipe for cooking.

### Characteristics of an Algorithm
- Clear: Every step is easy to understand.
- Finite: It ends after a limited number of steps.
- Effective: Each step can be carried out.
- Input: Takes zero or more inputs.
- Output: Produces at least one result.

> ITS A PSEUDOCODE

### EXAMPLES OF A ALGO:
```C
int x = 4;
while (x >= 0) {
    x--;
}

return x;
```

### EXAMPLES OF NOT A ALGO:

## A Priori vs A Posteriori Analysis

| Feature                          | **A Priori Analysis**                     | **A Posteriori Analysis**                |
| -------------------------------- | ----------------------------------------- | ---------------------------------------- |
| Meaning                          | Analysis **before running** the algorithm | Analysis **after running** the algorithm |
| Based on                         | Theoretical calculation                   | Experimental results                     |
| Depends on machine?              | **No**                                    | **Yes**                                  |
| Depends on programming language? | Generally **No**                          | **Yes**                                  |
| Main focus                       | Time/space complexity                     | Actual execution time/memory             |
| Example                          | O(n), O(n²), O(log n)                     | Algorithm took 0.5 seconds               |

## Asymptotic Analysis
> Asymptotic analysis is the method of analyzing an algorithm's time and space requirements as the input size n becomes very large.
- It helps us compare algorithms independent of machine, programming language, and hardware.


## Asymptotic Notations
- Asymptotic notations are mathematical tools used to describe the growth rate of an algorithm's time or space complexity as input size n becomes very large.
- There are three main notations:
1. Big-O — O
2. Big-Omega — Ω
3. Big-Theta — Θ

- Example: Linear Search

Suppose the element being searched can be anywhere in an array of n elements.

Best case: element is at the first position
→ Ω(1)
Worst case: element is at the last position or absent
→ O(n)
Tight bound: depends on what behavior you're describing. For the worst-case running time, it is Θ(n).
