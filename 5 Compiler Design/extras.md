## A Phrase-Structured Grammar (PSG) 
- is the most general type of grammar in the Chomsky hierarchy.
- It is also called an Unrestricted Grammar or Type-0 Grammar.
- is a type of formal grammar in which a sentence is generated by replacing grammatical symbols (non-terminals) with other symbols according to production rules.
> G=(V,T,P,S)

### Chomsky Hierarchy
- There are four types of grammars:

1. Type 0 — Unrestricted Grammar
Phrase-Structured Grammar

2. Type 1 — Context-Sensitive Grammar

3. Type 2 — Context-Free Grammar

4. Type 3 — Regular Grammar

## 1. Grammar → Language → Automata
1. Type 0	- Unrestricted / Phrase-Structured	
- Language Class :-> Recursively Enumerable (RE)	
- Automata :- Turing Machine (TM)

2. Type 1	- Context-Sensitive (CSG)	
Context-Sensitive Language (CSL)	
- Automata :- Linear Bounded Automaton (LBA)

3. Type 2	- Context-Free (CFG)	
Context-Free Language (CFL)	
- Automata :- Pushdown Automaton (PDA)

4. Type 3 -	Regular Grammar (RG)	
Regular Language (RL)	
- Automata :- Finite Automaton (FA)

## The two most important operations of a symbol table are:
1. Insertion: Adding a new identifier (name).
2. Lookup / Inquiry: Searching whether an identifier exists and retrieving its information.
Different symbol table implementations (arrays, linked lists, hash tables, binary search trees, etc.) are compared based on the time required for both operations.

## Abstract Syntax Tree
- An Abstract Syntax Tree (AST) is a tree representation of the source code that shows its logical structure while ignoring unnecessary syntactic details such as parentheses, commas, and other grammar-specific symbols.

1. (a) Syntax analysis phase output is an abstract syntax tree.
2. (b) Abstract syntax tree is a condensed form of parse tree.
3. (c) Abstract syntax tree should not have keywords as leaves.


## Incompletely Specified Automaton 
is a finite automaton in which the transition function is not defined for every state-input symbol combination.
In simple words, some transitions are missing or unspecified.
