## Linked representation of a stack
Each node contains two fields:
1. INFO	Stores the actual data/element
2. LINK	Stores the address of the next node

- TOP: A pointer that points to the topmost node of the stack.
- INFO: Holds the actual stack elements.
- LINK: Connects one node to another.
- NULL: Indicates the end of the linked list

Pointer	        Meaning
- Start pointer	Points to the first node (TOP)
- Avail pointer	Points to available/free nodes
- Stop pointer	Not the standard top pointer
- Begin pointer	Not the conventional pointer name here
