## 1. Limits
- A limit describes the value a function approaches as \(x\) approaches a particular number.
- Left-hand and right-hand limits
    - Left-hand limit (LHL): \(x\) approaches \(a\) from the left.
    - Right-hand limit (RHL): \(x\) approaches \(a\) from the right.
- 
1. lim(x->0) sinx/x = 1.
2. lim(x->0) tanx/x = 1.

## 4. Maxima and Minima
1. Basic definitions
- Local maximum: \(f(a)\) is at least as large as nearby function values.
- Local minimum: \(f(a)\) is at most as large as nearby function values.
- Absolute maximum: Largest function value on the entire specified domain or interval.
- Absolute minimum: Smallest function value on the entire specified domain or interval.

## 4.3 First derivative test
- Check the sign of \(f'(x)\) on either side of a critical point.
Sign change         	Conclusion
+ to -                  	Local maximum
- to +	                 Local minimum
+ to +                    No extremum
- to -	                 No extremum

## 4.4 Second derivative test
- At a stationary point c, where f'(c)=0:
Condition	            Conclusion
f''(c)>0              	Local minimum
f''(c)<0             	Local maximum
f''(c)=0            	Test inconclusive

## Critical points
- A critical point c is an interior point of the domain where
    - f'(c)=0
    - or the derivative does not exist.
- Critical points are candidates for local extrema, but not every critical point is a maximum or minimum.

## 4.5 Absolute extrema on a closed interval
For a continuous function on \([a,b]\):
1. Find critical points in \((a,b)\).
2. Evaluate \(f(x)\) at every critical point.
3. Evaluate \(f(a)\) and \(f(b)\).
4. Compare all values.
- The largest value is the absolute maximum; the smallest is the absolute minimum.
> Important: Do not ignore endpoints when the problem asks for extrema on a closed interval.

## 4.7 Concavity and inflection points
- \(f''(x)>0\): graph is concave upward.
- \(f''(x)<0\): graph is concave downward.
- An inflection point is a point where concavity changes.
