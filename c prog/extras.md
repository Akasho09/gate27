3. grid[i][j] = *(*(grid + i) + j);
| Expression              | Meaning                         |
| `grid`                  | Pointer to the first row        |
| `*grid`                 | First row of the array          |
| `**grid`                | Value of the first element: `2` |
| `grid + 1`              | Pointer to the second row       |
| `*(grid + 1)`           | Second row of the array         |
| `*(*(grid + i) + j)`    | Element at row `i`, column `j`  |
| `*(grid + i)` | Row `i` |
